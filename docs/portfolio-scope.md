# 공개 범위와 갱신 기준

이 저장소는 제품 소스 배포판이 아니라 공개 포트폴리오다. private 원본을 자동 복제하지 않고, 검증된 결과 중 공개에 적합한 항목만 수동으로 선별한다.

## 포함하는 항목

- 프로젝트 문제와 목표 사용자 경험
- 구현·설계·계획을 구분한 현재 상태와 로드맵
- 상위 서비스 경계와 공개 가능한 데이터 흐름
- 기술 선택의 이유, 대안과 트레이드오프
- `AGENTS.md` 계층과 문서 기반 AI 보조 개발 방식
- 테스트 데이터로 만든 스크린샷, 짧은 데모와 결과 요약

## 포함하지 않는 항목

- Web·API·AI·인프라 제품 소스와 생성 코드
- 전체 데이터베이스 스키마, private Git 이력과 내부 작업 백로그
- 비밀정보, 실제 환경 변수, 토큰, 내부 호스트와 네트워크 정보
- 원문 로그, 실제 사용자 데이터와 개인 메모
- 공격에 바로 활용될 수 있는 운영 보안 세부
- 사용 권리를 확인하지 않은 이미지, 글꼴과 영상

## 갱신 시점

- 사용자에게 보여줄 수 있는 세로 기능이 실제 검증됐을 때
- 상위 아키텍처나 주요 기술 판단이 구현으로 확인됐을 때
- 화면·데모·테스트 결과 또는 공개 로드맵이 달라졌을 때
- 기존 공개 설명과 private 원본의 상태가 달라졌을 때

작은 내부 커밋마다 동기화하지 않는다. 공개 내용에는 확인일을 남기고, 구현되지 않은 기능은 설계 또는 계획으로 표시한다.

## 공개 전 확인

- [ ] 모든 구현 완료 주장을 private 원본의 코드·테스트·CI 결과로 확인했다.
- [ ] 문서가 private 저장소 없이 독립적으로 읽힌다.
- [ ] 깨진 로컬 링크와 private 문서 링크가 없다.
- [ ] 비밀정보, 내부 주소, 절대 로컬 경로와 원문 로그가 없다.
- [ ] 이미지와 영상에 개인 데이터가 없고 사용 권리를 확인했다.
- [ ] 보안 내용이 상위 원칙을 넘어 악용 가능한 세부를 노출하지 않는다.
- [ ] Markdown과 Mermaid가 public GitHub에서 정상 렌더링된다.
