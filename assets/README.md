# 시각 자료 안내

M2 첫 세로 기능이 완료된 뒤 다음과 같은 공개 자료를 추가한다.

```text
assets/
├── screenshots/
│   ├── author-studio.webp
│   ├── story-editor.webp
│   └── event-graph.webp
└── demos/
    └── author-flow.mp4
```

## 추가 기준

- 실제 구현 화면만 사용하고 목업은 목업임을 명확히 표시한다.
- 테스트 계정과 가상 작품 데이터를 사용한다.
- 계정명, 이메일, 알림, 브라우저 북마크와 운영 주소를 제거한다.
- 이미지 메타데이터와 영상 오디오에 개인 정보가 없는지 확인한다.
- GIF보다 용량 효율이 좋은 WebP·MP4를 우선 검토하되 GitHub 미리보기 호환성을 확인한다.
- 직접 만들지 않은 이미지·글꼴·음원은 사용 권리와 출처를 함께 기록한다.
- 아직 공개 자료가 없을 때 깨진 이미지 링크나 가짜 제품 화면을 추가하지 않는다.
